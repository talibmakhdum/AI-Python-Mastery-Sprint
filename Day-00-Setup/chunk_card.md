======================================================
       CHUNK CARD: DAY 0 - SETUP (Mnemonic: SETUP)   
======================================================

S - SOFTWARE: Python 3.11, pip, venv
    Activate: source venv/Scripts/activate

E - EDITOR: VS Code + Extensions (Python, Pylance, Jupyter, GitLens)

T - TERMINAL COMMANDS:
    pwd      -> print working directory
    ls       -> list files
    cd       -> change directory
    mkdir    -> make directory
    python   -> run python script

U - UPLOAD (GIT):
    git status  -> check changes
    git add .   -> stage all
    git commit -m 'msg' -> save checkpoint
    git push    -> send to GitHub
    git pull    -> get latest

P - PROJECT/PORTFOLIO: GitHub repo organized by day.
    NEVER push venv/ or .env files.
